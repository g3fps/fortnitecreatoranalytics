Where these numbers come from

Every stat here is pulled from Epic's own public Ecosystem API — the same engagement metrics that feed Creative/UEFN engagement payouts. Epic's API only ever reports an island's current reading, with no history, so this site captures a reading for each island regularly and keeps it. That's why the trend lines and Movers view exist here and nowhere else: the history only exists because it was recorded as it happened. Stats update about once a day (which is as often as Epic's underlying numbers change). Not affiliated with or endorsed by Epic Games.
